# The Factory and CityW mobile app

Both tabs load their official mobile stores. The catalogue, product images, details, price and availability come from the live websites. The websites also handle accounts, cart and checkout. Use the browser button if a payment or sign-in provider requires the system browser. Test both stores on real devices before distribution.

Upload this directory as the root of a GitHub repository, including .github. Run Build Almutlaq mobile apps from the Actions tab. The Android job generates a debug APK. The macOS job generates an unsigned IPA, which requires signing before normal iPhone installation.

Optionally publish the three files in ar-preview on HTTPS. Enter the index.html URL in the workflow ar_url input to enable the View in your room button when the London three-seater product page is open. The bundled model is a simplified reference.
